Why TermProof?

Most TUI testing stops at “stdout contains X”. TermProof records the real session and makes evidence reviewable.

When to use what

Use VHS if…

You need a marketing GIF quickly. Write a tape, get a GIF. No assertions needed.

Use expect if…

You need low-level PTY scripting and you will build your own assertion/report layer.

Use Playwright if…

You're testing web, not terminal. It cannot drive ANSI / PTY / Ink renderers.

Use TermProof if…

You want evidence that survives a PR review: cast, screenshots, video, report, CI gate, release attachment.

Design principles

  • Cast is source of truth — screenshots, videos, text snapshots all derive from the same recording.
  • Recipes are portable — JSON, versioned, checked into repos near the product.
  • Evidence over log line — reviewers inspect what happened, not a green check.
  • Deterministic by default — Pi workflows use scripted fixtures, not live provider calls, in public CI.
  • Product-agnostic — any CLI/TUI binary works via command.argv.
