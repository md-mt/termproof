Getting Started

3 commands → proof. Works for any TUI: Textual, Bubble Tea, Ratatui, Ink, curses.

1

Install

pip install git+https://github.com/md-mt/termproof.git
# or from source
git clone https://github.com/md-mt/termproof.git && cd termproof
uv run termproof --help

Requires Python 3.11+. For video: ffmpeg + agg (Rust). cargo install --locked --git https://github.com/asciinema/agg --tag v1.9.0

2

Scaffold a recipe pack

termproof init .termproof/recipes --name my-tui --command "my-tui"
cat .termproof/recipes/my-tui.recipe.json

The init command writes a minimal JSON recipe with command.argv, pty=true, one wait step and one assertion. Edit it to match your TUI prompts.

3

Run with evidence

termproof run .termproof/recipes --video --out .termproof/runs
# inspect artifacts (macOS: open; Linux: xdg-open)
open .termproof/runs/*/session.mp4
cat .termproof/runs/*/latest-report.md

Each run writes session.cast (asciinema v2), final.svg, final.txt, steps/, session.mp4, result.json, report.md.

Recipe anatomy

{
  "name": "my-tui-main-flow",
  "description": "Open dashboard, filter, export.",
  "priority": "P0",
  "execution": "scripted",
  "determinism": "deterministic",
  "checks": ["dashboard opens", "filter applies", "export completes"],
  "command": { "argv": ["my-tui"], "pty": true },
  "timeout_seconds": 30,
  "cols": 100,
  "rows": 30,
  "steps": [
    { "action": "wait_for_text", "text": "my-tui>", "timeout_seconds": 5 },
    { "action": "send_line", "text": "open dashboard" },
    { "action": "wait_for_text", "text": "DASHBOARD READY" }
  ],
  "assertions": [
    { "type": "output_contains", "value": "DASHBOARD READY" }
  ],
  "expect_exit_code": 0
}

Step actions

ActionDescription
wait_for_textWait until terminal output contains text
wait_for_idleWait until no output for N seconds
wait_for_countWait until text appears N times
send_textSend text without newline
send_lineSend text + Enter
pressSend key (e.g., enter, escape, tab)
sleepWait N seconds

Assertions

TypeDescription
output_containsRaw output contains string
output_not_containsRaw output does NOT contain string
screen_containsFinal screen text contains string
screen_not_containsFinal screen text does NOT contain
exit_codeProcess exit code equals expected
file_existsFile exists after run
file_containsFile contains string
