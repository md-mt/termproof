Don't trust the log.
Ship the proof.

TermProof is an evidence-first harness for terminal and TUI apps. It drives your TUI from JSON recipes, records the real PTY to an asciinema-format cast, replays it into SVGs and MP4s, and writes reviewable reports. Pi agent workflows are the flagship showcase.

Get started in 3 commands → View sample evidence

What is it?

Recipe → PTY → Cast

JSON recipes describe how to drive your TUI. The runner spawns a real pexpect PTY — not a mock — and writes the session out in asciinema v2 format itself; the asciinema CLI is optional, behind termproof[record]. The cast is the source of truth.

Screenshots + Video

Every step writes a screenshot and text snapshot. final.svg is rendered in colour from the terminal grid; the per-step images are rendered from plain text. With --video, agg + ffmpeg render a 60-fps MP4 from the same cast.

Reports + PR Comments

latest-report.md embeds assertion tables and evidence links. CI posts a sticky comment on every PR and uploads termproof-ci-evidence.

3-command quickstart

pip install git+https://github.com/md-mt/termproof.git
termproof init .termproof/recipes --name my-tui --command "my-tui"
termproof run .termproof/recipes --video --out .termproof/runs

Artifacts: session.cast, final.svg, final.txt, session.mp4, steps/, result.json, report.md, latest-report.md

CI snippet (GitHub Actions)

- name: Install agg + ffmpeg
  run: |
    sudo apt-get update && sudo apt-get install -y ffmpeg
    if ! command -v agg >/dev/null 2>&1; then
      cargo install --locked --git https://github.com/asciinema/agg --tag v1.9.0
    fi
- name: Run TermProof
  run: uv run termproof run .termproof/recipes --video --video-fps 60 --out .termproof/ci
- name: Upload evidence
  uses: actions/upload-artifact@v4
  if: always()
  with:
    name: termproof-ci-evidence
    path: .termproof/ci
- name: Summary
  if: always()
  run: cat .termproof/ci/latest-report.md >> "$GITHUB_STEP_SUMMARY"

This is the verification portion of ci.yml as used in this repo. A complete downstream workflow also needs Python + uv setup and a TermProof install step. See the full workflow for the complete template.
