Plugin directory

TermProof is extensible via registries: steps, assertions, session backends, video backends, reporters, execution modes, agent runners. List your plugin here via PR.

How to add a plugin

# .termproof/config.yaml
steps:
  wait_for_regex: my_org.termproof_steps:WaitForRegexStep
assertions:
  json_schema: my_org.termproof_assertions:JsonSchemaAssertion
session_backends:
  docker: my_org.termproof_session:DockerSessionBackend
reporters:
  junit_xml: my_org.termproof_reporters:JunitReporter

See recipe-packs.md and termproof/config.py for built-ins.

Publishing guidelines

  1. Name: termproof-<integration> (e.g., termproof-textual)
  2. Expose module:Class references and document them in README.
  3. Include a recipe pack under examples/ or recipes/ and a CI job running termproof run --video.
  4. Add Verified by TermProof badge — see verified-badge.md.
