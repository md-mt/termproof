# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in TermProof, please report it privately rather than opening a public issue.

**Contact:** md@mt.com

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including a minimal recipe if applicable
- The affected version(s)
- Any suggested mitigations

We aim to acknowledge reports within 48 hours and provide an initial assessment within 5 business days.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

## Disclosure

We follow coordinated disclosure. After a fix is released, we will credit the reporter (unless they prefer to remain anonymous) and publish an advisory.
